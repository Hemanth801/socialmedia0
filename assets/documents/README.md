# Resume & Documents

This folder is for storing downloadable documents.

## How to Add Your Resume

1. **Create or prepare your resume** as a PDF file
2. **Name it** `resume.pdf`
3. **Place it** in this folder (`assets/documents/`)
4. The download button will automatically work

## File Naming Convention

- Main Resume: `resume.pdf`
- Alternative formats: `resume.docx`, `resume.txt`

## Updating Resume

Simply replace the `resume.pdf` file with your updated version. The website will automatically link to the new file.

## Privacy Notes

- Keep sensitive information (full address, personal details) minimal
- Focus on professional skills and achievements
- Use a professional email and phone number

---

**Once you add your resume.pdf file here, the download button on the portfolio will be fully functional.**
